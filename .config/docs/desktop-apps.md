# Desktop app configs

Smaller, mostly self-contained app configs tracked in this repo.

## rofi

`~/.config/rofi/config.rasi` — icons on (Papirus theme), stacks three
`.rasi` files: system `Pop-Dark`, system `glue_pro_blue`, then this repo's
own `materialyou.rasi` last (so it wins on conflicting properties). That
last file is **generated by `gen-theme.py`** and not tracked — see
[theming.md](theming.md). Launched via `mainMod+Super_l` (tap-to-release,
`pkill rofi || rofi -show drun`) and used as the picker UI for
`notifyd-actions-menu.sh` and `appmenu-atspi.py` — see
[hyprland.md](hyprland.md).

## mpv

`~/.config/mpv/mpv.conf` — minimal OSD (no on-screen controller, no seek
OSD text, no timer), position/subtitle state persisted across quits
(`save-position-on-quit`, `no-resume-playback` — so it saves but never
auto-resumes), infinite `image-display-duration`, PNG screenshots to
`~/screenshots` at max compression, `pulse` audio output, per-extension
`loop-file=inf` for webm/gif/mp4/mkv (treats short clips as loops by
default). `input.conf` remaps `hjkl` to 5s/60s seeks (vim-style,
consistent with this setup's other vi-mode bindings) and adds
`Shift+Delete` to actually delete the current file from disk.

## nsxiv

`~/.config/nsxiv/exec/key-handler` — the `C-x`-prefixed action script sxiv
calls with the marked/current image paths on stdin. Custom actions:
`C-x` copy paths to clipboard, `C-c` copy image data (PNG) to clipboard,
`c` copy realpath, `d` delete, `o` open in Nemo, `g`/`C-g` open in GIMP,
`C-e` show EXIF via `exiv2` in an Alacritty popup, `r`/`R` rotate 90°/270°
(JPEG-lossless via `jpegtran` when the file is actually a JPEG, `mogrify`
otherwise). `~/.config/nsxiv/xresources` (the `Nsxiv.*` X resource colors)
is generated by `gen-theme.py`, not tracked — see
[theming.md](theming.md#what-gen-themepy-writes).

## fsearch

`~/.config/fsearch/fsearch.conf` — dark theme, single-click-open off,
launches `.desktop` files directly, restores column/sort config. Backed by
`fsearch --update-database`, refreshed by an untracked local systemd timer
(`fsearch_update_database.timer`, not part of this repo).

## GTK

`~/.config/gtk-{3,4}.0/settings.ini` — dark theme forced
(`gtk-application-prefer-dark-theme=true`, `gtk-theme-name=adw-gtk3-dark`),
Papirus-Dark icons, Sweet cursors, `Noto Sans 10`. GTK3's `gtk-modules`
loads `window-decorations-gtk-module:colorreload-gtk-module:appmenu-gtk-module`
— `colorreload-gtk-module` is what makes GTK3's live wallpaper-driven
recolor work (see [theming.md](theming.md)). `colors.css` (the actual
`@define-color` values) is generated, not tracked; `gtk.css` (a static
`@import "colors.css";` shim) is tracked. `~/.gtkrc-2.0` is a legacy GTK2
override (mismatched theme name `Infinity-GTK`/`Tela-blue-dark`, predating
the GTK3/4 dark-theme + Material You setup — GTK2 apps are rare enough on
this system that it hasn't been revisited). See
[[gtk_theme_white_root_cause]] memory for the incident this setup is built
to avoid (dconf pointing at an uninstalled theme name → white GTK apps).

## `.local/share/applications/` overrides

Only four `.desktop` files are actually tracked here (everything else
under this directory on disk is untracked — system-provided, firecfg
conversions, or KDE global-shortcut placeholders):

- `alacritty-emacsclient.desktop` — "Emacs (Terminal)", opens files via
  `alacritty -e tmux new-session emacsclient --tty %F`.
- `brave-browser.desktop` — user override of the system entry, adding
  `--force-renderer-accessibility` so Chromium always builds its AT-SPI
  tree (needed for `mainMod+A`'s global-menu picker — Chromium otherwise
  only builds it when it detects an AT client, which never happens
  organically). Kept in sync manually if Brave updates the system file.
- `librewolf.desktop` — same idea, `GNOME_ACCESSIBILITY=1` forces Gecko's
  a11y bridge on for the same reason. Note: originally "converted by
  firecfg" and firecfg re-running will regenerate/overwrite it, dropping
  the env var — re-apply after any firecfg run.
- `claude-code-url-handler.desktop` — registers the `claude-cli://` URI
  scheme handler (`claude --handle-uri %u`).

## waybar (legacy)

`~/.config/waybar/config.jsonc` + `style.css` are **still tracked** but
**no longer autostarted** — `hyprland.lua`'s `hl.exec_cmd("waybar")` line
has been commented out since 2026-08-27 in favor of the quickshell bar (see
[quickshell-bar.md](quickshell-bar.md)). Not formally archived, so it's
documented here rather than dropped:

- Docked, exclusive-zone bar (30px row, `modules-left`:
  workspaces/submap, `modules-center`: window title, `modules-right`:
  tray/mpris/controls/network/hardware/clock), each module group its own
  rounded pill via CSS.
- `mainMod+B` sends `SIGUSR1` (waybar's built-in toggle-visibility signal)
  — this keybind is **still wired up** in `keybinds.lua` even though
  waybar itself isn't running, so it's currently a no-op unless waybar is
  manually started.
- `waybar-mpris.sh` — polled via waybar's `interval` config, deliberately
  **not** a self-looping continuous-mode script: that was tried first and
  reliably went stale mid-playback (waybar stopped picking up new stdout
  lines after a while, despite the script's own internal state tracking
  correctly) — see [[waybar_continuous_module_goes_stale]] memory. Also
  see [[waybar_custom_module_max_length_bug]] and
  [[waybar_multi_monitor_interval_cpu_cost]] for two other waybar-specific
  bugs found while this was still the active bar (max-length silently
  hides a module entirely in 0.15.0; interval-based CPU cost multiplies
  per connected monitor).

**Rollback**: uncomment the `waybar` line in `hyprland.lua`'s autostart
block and kill/disable `qs -n -d` if running (see the comment right above
that line).
