zsh, bash, Doom Emacs, Alacritty

bash

.bashrc is a fallback/secondary shell config (zsh, above, is primary). Notably: auto-starts (or attaches to) a uniquely-named tmux session the instant an interactive bash shell opens outside of tmux (auto-$(basename "$SHELL")-$$), then exits the shell when tmux exits — so a bare bash login always lands inside tmux. Also wraps the pass command: pass open (bare, no extra args) auto-closes the password-store coffin after 300s by spawning a tagged background sleep (_PASS_AUTOCLOSE_TIMER_ via exec -a), killing any previous still-running timer first — a no-systemd-timer alternative to a real auto-lock. EDITOR=emacsclient -t; ec/et helpers create-frame/attach-tty an emacsclient.

zsh

  • .zshenv — sourced by every zsh (login, interactive, and scripts — including ones spawned by a pre-existing tmux server, which .zshrc alone wouldn't cover). Currently just XDG_MENU_PREFIX=plasma-, closing the terminal/tmux gap left by hypr/environment.lua's own export of the same var (which only covers Hyprland's own children + systemd/dbus activation env) — see hyprland.md and ksycoca_menu_prefix_poisoning memory for the full KSycoca incident this fixes.
  • .zshrc — vi-ish history handling (HIST_IGNORE_ALL_DUPS, SHARE_HISTORY, 99M-line HISTFILE), case-insensitive completion, fzf widgets (M-x execute, C-r history), cd history navigation (M-Right/M-Left/M-Up via _cd_next_dir/_cd_prev_dir/cd_up), emacs-style C-Left/C-Right word motions, ^Z/^Y undo/redo. Sources motions.zsh (below) at line 70.
  • .config/zsh/motions.zsh — custom Emacs-style word-motion widgets that respect quoted strings (so a motion doesn't stop in the middle of a quoted path/argument): backward_over_quoted_string / forward_over_quoted_string (quote-aware cursor stepping, handling escaped quotes) build backward-full-word / forward-full-word / kill-backward-full-word.

Doom Emacs

~/.config/doom/ — config.el (theme doom-one, initial-major-mode org-mode, vertico cycle off), init.el (module selection: vertico + corfu completion, evil everywhere, magit, tree-sitter, org, dired, undo-tree, snippets/file-templates — most language modules deliberately disabled), packages.el (two personal packages pulled straight from GitHub: baleti/git-branch-off and baleti/gitq's emacs integration).

Launched via mainMod+SHIFT+e (alacritty -e tmux new-session emacsclient --tty, see hyprland.md) or the tracked alacritty-emacsclient.desktop entry — see desktop-apps.md. Its former +magit/* custom layer and custom.el were archived out (moved to a separate git repo — see the 047f79f/319b775 commits); don't expect them in the working tree.

Alacritty

~/.config/alacritty/alacritty.toml — JetBrains Mono 10pt, block cursor, 10000-line scrollback, live_config_reload = true. Colors are not inline: [colors] only sets draw_bold_text_with_bright_colors, the actual [colors.primary/normal/bright] tables live in a separate ~/.config/alacritty/colors.toml pulled in via [general] import. That file is generated by gen-theme.py from the wallpaper (see theming.md) and deliberately not tracked in git, so the 15-minute wallpaper rotation never churns this file's history.

Custom keyboard bindings beyond Alacritty's stock defaults, all CSI-u sequences needed by tmux's extended-keys always / Claude Code to see otherwise-ambiguous key combos:

  • Shift+Enter → \x1b[13;2u, Ctrl+Enter → \x1b[13;5u, Ctrl+Shift+Enter → \x1b[13;6u
  • Shift+Space → \x1b[32;2u
  • Ctrl+. → \x1b[46;5u
  • Ctrl+Shift+V/C and Ctrl+Alt+V/C → Paste/Copy (both modifier combos, since Ctrl+Shift+C/V collide with the terminal's default SIGINT- adjacent bindings on some layouts)

See tmux_extended_keys_shift_enter memory: Alacritty already sends these fine, it was tmux silently reverting extended-keys always on some config paths that caused the actual bug.

GnuPG

.gnupg/gpg-agent.conf — enable-ssh-support, pinentry-program /usr/bin/pinentry-gtk. .gnupg/gpg.conf — use-agent. Ssh-agent duties (for git signing / remote auth) are handled by gpg-agent rather than a separate ssh-agent.
